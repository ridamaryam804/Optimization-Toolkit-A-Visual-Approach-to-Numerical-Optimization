# Optimization-Toolkit-A-Visual-Approach-to-Numerical-Optimization

A visual numerical optimization tool with interactive GUI for comparing Golden Section Search, Newton's Method, and Gradient Descent.
 # Quick Start
 Install dependencies:
 pip install streamlit numpy matplotlib sympy pandas

 # Run the application:
streamlit run Optimization.py

 # Features
  # 3 Optimization Methods:

1: Golden Section Search (derivative-free)
2: Newton's Method (uses derivatives)
3: Gradient Descent (iterative optimization)
4: Interactive GUI with Streamlit
5: Real-time plotting with Matplotlib
6: Upload CSV/Excel data for real-world optimization
7: Comparison tool for all methods
8: Export results to CSV
